# Appendix C screenshot index (live local run)

Every capture comes from a live local run of commit `0e87172` on 2026-10-12, between 16:40 and 16:50 (+08:00). The app ran against the disposable `caresync_evidence` database with email disabled and the clinic clock simulated at Tue 2026-10-13 08:45. The browser was headless Edge 155 at a 1440x900 viewport, driven by the scripts in `../tools/`. Setup, accounts and general limitations are in [`../README.md`](../README.md).

**Production method:**

- **UI:** a real UI action captured as a viewport or full-page image.
- **UI-dialog:** a real UI dialog expanded to full height for capture.
- **API-render:** real API responses, sanitized, rendered by the harness.
